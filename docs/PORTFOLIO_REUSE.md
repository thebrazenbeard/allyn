## Boundaries

- Source code or successful unit tests do not demonstrate a live autonomous AI.
- Recursion is not itself learning; a Y-combinator is not a generalization rule.
- Language transfer must beat explicit controls on held-out, source-separated
  data before it can be called successful teaching.
- Prediction must be committed before the matching outcome is used for an update.
- Evidence, inference, hypothesis, advice, and protected effects remain distinct.
- No Vera-specific identity, autobiography, private data, or runtime authority is
  inherited by ALLYN.
- Cross-repository reuse requires license/provenance review and exact version
  binding. Shared ownership does not automatically resolve license terms.
- `noema`, `the-director`, and `semanticatlas` carry source-available proprietary
  license restrictions. ALLYN independently reimplements small interface ideas;
  no third-party source is vendored by this prototype.
- The initial implementation is a standalone, offline experimental prototype,
  not a trained neural model or a consciousness claim.
